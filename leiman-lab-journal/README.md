Рабочий прототип авторского журнала Льва Леймана. Версия handoff 2026-10-23.

- Сайт: https://journal-production-3e67.up.railway.app/ (прежний адрес перенесён на новый сервис, старые ссылки из Telegram открывают новую версию)
- Запасной адрес того же сервиса: https://journal-web-production-bf39.up.railway.app/
- Статьи: `/articles/warhound`, `/articles/black-october`
- Railway: проект `leiman-lab-journal` → сервис `journal-web` (`10578a57-b8ae-470f-bf64-623605e504df`), источник GitHub `lleiman/chapter-site`, ветка `leiman-lab-journal`, root `/leiman-lab-journal`
- Автодеплой: любой push в ветку `leiman-lab-journal`, затрагивающий `leiman-lab-journal/**`, сам пересобирает сервис. Публикация новой статьи = commit + push.
- Старый Railway Function `journal` оставлен без домена для отката; его можно удалить, когда новая версия поживёт без проблем.

## Редактор на сайте

- Открыть: `⌘⇧E` (Mac) / `Ctrl+Shift+E` или `?edit` в адресе. Работает на главной и на страницах статей.
- Пароля нет (решение автора, 23.10.2026): редактор открывается любому, кто нажмёт сочетание клавиш. Откат чужой правки — «Сбросить к Git» или файл из `/data/history/`. Чтобы снова включить пароль, задать переменную `ADMIN_PASSWORD` сервису `journal-web` в Railway.
- Правится текст на месте: заголовок, подзаголовок, абзацы, выноски, подписи ссылок, источники, тексты главной. Enter в абзаце — новый абзац; стёртый целиком абзац удаляется. Кнопка «Превью и карточка» — заголовок и текст карточки, описание для Telegram.
- Правки хранятся на томе Railway (`/data`, `DATA_DIR`) и главнее файлов из Git: `/data/articles/<slug>.json`, `/data/site.json`, 100 последних версий в `/data/history/`. «Сбросить к Git» удаляет правку и возвращает версию из репозитория.
- Если статью правили в редакторе, а потом поменяли её JSON в Git, на сайте останется версия из редактора, пока её не сбросить.

## Просмотры, лайки, комментарии

- Код: `engagement.mjs` (сервер, хранение), `public/assets/engage.js` (страница статьи). Данные — `/data/engagement.json` на томе; удалённые комментарии остаются там же в `deleted` (последние 500).
- Просмотр: скрипт страницы шлёт `POST /api/views/<slug>`; засчитывается один раз на человека (хеш IP + браузер) на статью в сутки, боты и сборщики превью (TelegramBot, curl и т. п.) не считаются. Ваши собственные заходы тоже считаются.
- UTM-метки: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` из адреса уходят на сервер вместе с просмотром и «дочитал», после этого скрипт убирает их из адресной строки, чтобы пересланная читателем ссылка не приписывала чужие заходы посту. Ссылка для анонса: `/articles/<slug>?utm_source=telegram&utm_medium=messenger&utm_campaign=<slug>&utm_content=<номер поста>` — готовая есть в статистике редактора. Учёт меток начат 24.10.2026.
- «Дочитал»: один раз на человека на статью в сутки — 30 секунд, пока текст статьи на экране в видимой вкладке, или прокрутка до 75% текста (от начала текста до блока источников, комментарии не считаются).
- Статистика статьи: ⌘⇧E → «Статистика» — просмотры, дочитали и их доля, лайки, комментарии, таблица по меткам (`GET /api/admin/stats/<slug>`).
- Лайк: один на браузер (случайный id в localStorage), повторное нажатие снимает.
- Комментарии: публикуются сразу, имя необязательно, до 2000 знаков, ответы в один уровень. Можно выделить фрагмент текста и прокомментировать его — фрагмент подсвечивается, по нажатию открывается обсуждение. Если текст правили и фрагмент исчез, комментарий остаётся в списке с пометкой.
- Защита от спама: скрытое поле-ловушка, не больше 5 комментариев за 10 минут и 30 в сутки с одного адреса, только JSON-запросы со своего сайта.
- Удаление: посетитель удаляет свои; в режиме редактора (⌘⇧E) у всех комментариев есть «Удалить».
- API: `GET /api/engagement/<slug>?visitor=`, `POST /api/views/<slug>` и `POST /api/reads/<slug>` с `{utm}`, `POST /api/likes/<slug>`, `POST /api/comments/<slug>`, `DELETE /api/comments/<slug>/<id>`.

## Быстрый запуск

1. Нужен Node.js 20+.
2. В терминале из корня распакованного проекта:

```bash
npm start
```

3. Открыть `http://localhost:3000`.
4. Проверить `http://localhost:3000/articles/warhound` и `http://localhost:3000/articles/black-october`.
5. Запустить `npm test`. Здесь нет npm-зависимостей. `npm install` не требуется.

### Что внутри

- `server.mjs` — рабочий HTTP-сервер и SSR страниц, без внешних пакетов;
- `content/*.json` — независимые публикации, доступные для редактирования;
- `public/assets/site.css` — дизайн-система;
- `public/assets/warhound-1200x630.png` — подготовленная из ранее созданной редакционной иллюстрации карточка;
- `public/assets/black-october-1200x630.png` — отдельная типографическая карточка;
- `public/assets/leiman-lab-monogram.png`, `public/favicon.svg` — фирменная геометрическая монограмма;
- `railway.json` — настройки Railway (healthcheck, startCommand);
- `tests/smoke.mjs` — тесты страниц, картинок и Open Graph;
- `docs/CLAUDE_TASK.md` — полное задание Claude;
- `docs/STATE_AND_HANDOFF.md` — хронология работ, ID, проблемы и ограничения;
- `docs/VISUAL_SYSTEM.md` — визуальный код бренда и правила вёрстки;
- `docs/EDITORIAL_RULES.md` — редакционная политика, анти-клише;
- `docs/DEPLOY.md` — сценарий безопасного подключения к Railway;
- `docs/TELEGRAM_POSTS.md` — тексты для коротких постов.

## Принцип публикаций

Добавить новую статью `content/003-name.json`, повторить схему полей существующей статьи, положить PNG-обложку в `public/assets`. Сервер сам создаст страницу `/articles/name`, ссылку на главной и Open Graph метатеги. Перезапустить процесс или сделать commit для Railway-автодеплоя.

## Приватность и безопасность

Сайту **не нужны** ключи API, база данных, переменные окружения от других проектов или доступ к Google Drive. Не публиковать личные секреты в репозитории. В октябре 2026 Railway сообщила об инциденте, затронувшем переменные окружения: отдельная проверка и ротация секретов относятся к операционной безопасности, а не к этой публикационной задаче.
