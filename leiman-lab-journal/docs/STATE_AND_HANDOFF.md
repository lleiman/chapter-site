# Текущая ситуация и журнал событий

Дата: 23 октября 2026. Этот документ предназначен Claude, который продолжит проект вместо ChatGPT.

## 1. Суть

Лев Лейман ведёт авторский Telegram-канал **Leiman Lab** (ранее «Лев × Алекс / AI Adepts», канал @aiadepts). Нужен независимый редакционный сайт, куда публикуются полные статьи. В Telegram остаётся короткий анонс и native Open Graph превью. Нажатие на карточку открывает страницу во встроенном браузере Telegram там, где это поддерживается.

Направления: AI/технологии; R&D/сознание/психология; продакшен/бизнес; искусство/эксперименты. Контакт по коммерческим задачам @leimanleo.

## 2. Что уже было фактически сделано

1. Согласован визуальный язык **строгий швейцарский модернизм / редакционный брутализм**, чёрный, почти белый, красный, типографика, геометрическая LL-монограмма. Без свечения, sci-fi планет, бегущих строк, декоративной «кибер» перегрузки.
2. В Railway создан проект `leiman-lab-journal` (см. ID ниже).
3. В нём создан Railway Function `journal`, содержащий первоначальную версию сайта с одной статьёй («Чёрный октябрь»).
4. Домен Railway открыт публично; проверка 23 октября показала, что главная `/`, `/articles/black-october` и `/health` отвечают. Статья Warhound возвращала HTTP 404, значит публикация новой версии отсутствовала.
5. Попытки изменить Railway через плагин ChatGPT стали завершаться ошибкой `link_id must identify an eligible linked account`; в UI наблюдалась ошибка OAuth `invalid_request - could not validate id_token_hint`. Это ошибка контекста приложения/авторизации; не стоит делать вывод о неисправности аккаунта Railway.
6. Через доступный GitHub-плагин в репозитории `lleiman/chapter-site` создана новая ветка `leiman-lab-journal`. Там были добавлены сервер, CSS, JSON двух статей и README. Эти файлы **не были связаны с Railway через рабочий деплой**.
7. Этот ZIP — автономная улучшенная и проверяемая версия редакционного сайта. Её необходимо считать исходным кодом для дальнейших изменений и тестирования. Если в GitHub-ветке есть изменения, сначала сравнить и затем синхронизировать, не теряя полезные части.

## 6. Модель материала

Telegram — короткий самостоятельный авторский текст (длина до экрана) + URL, создающий встроенное превью. Сайт — текст со спокойной подачей, первоисточниками, статусом фактов, размышлением автора. Отдельный OG thumbnail для статьи. Не обещать Telegram Instant View: для него нужна отдельная конфигурация; Telegram in-app Browser и Instant View не одно и то же.
