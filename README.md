# ГЛАВА I · ПЕРЕВАЛ

Сайт одной главы романа «ТехноШаман». Третий в семействе: `model-site` —
документ персонажа, `synopsis-site` — синопсис, этот — сама проза.
Вёрстка, палитра, плеер и ворота `Burn me` общие.

## Глава

Том I «Город» → часть 1 «Перевал» → глава 1 из 9, страницы 22–30
по структуре на 999 страниц. Около 1300 слов.

Казе пересекает горный перевал на мотоцикле: смерч над равниной, руны
на дорожном указателе, зарождающаяся радуга. Пустое небо без птиц.
Брошенные машины на обочине, все носом вниз, к равнине, — ни одна
не развёрнута к перевалу. С седловины она впервые видит долину
в замкнутом кольце гор и город, которого нет на карте: без единого
огня, с медленно движущимся слоем воздуха над крышами. Глава кончается
там, где начинается вторая, — до встречи со слепым.

Открывающие абзацы — авторский чистовик. Остальное дописано по
опорной сцене 1 и по новому материалу части 1 («дорога до перевала:
откуда она едет и почему одна, ровно столько, чтобы не объяснить»).

## Устройство

```
index.html                — разметка и весь текст главы
assets/css/style.css      — оформление, переменные в :root
assets/js/main.js         — прогресс чтения, плеер, ворота
assets/img/logo.png       — логотип проекта
assets/audio/*.mp3        — три файловых трека
```

Ни сборки, ни зависимостей, ни CDN. Открывается двойным кликом
по `index.html` и работает офлайн.

### Типографика

Обложка типографская: чёрное поле, тлеющее пятно снизу, номер главы
и название. Кадра нет намеренно — вход в главу должен быть текстом.

Полоса набора 640px, кегль 18px, интерлиньяж 1.85, мягкие переносы.
Буквица на первом абзаце, разделители сцен точкой цвета угля.
Якорные фразы вынесены в моноширинный с крупным трекингом.

### Звук

Четыре трека, включаются кликом по воротам `Burn me`: **The Machine’s
Lullaby**, **De Trave**, **Her Soul** и **Inferno** — генеративный эмбиент,
который синтезируется в браузере и ничего не грузит. Пока играет
«Her Soul», всплывает ссылка на документ Модели.

## Проверка

```bash
python3 -m http.server 8000
```

Войти через `Burn me`, прокрутить главу до конца, проверить ширину 375px.

## Хостинг

Caddy из `Dockerfile` + `Caddyfile`, пароля нет.
